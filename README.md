# Smart Vitals Dashboard

A biomedical engineering learning project.

## What am I building?

A simple web dashboard that displays simulated patient readings:
- Heart rate
- Blood oxygen saturation (SpO2)
- Body temperature
- Breathing rate

## How will it work?

1. Load fictional patient readings.
2. Display the readings in a dashboard.
3. Compare them with demonstration alert rules.
4. Highlight readings that trigger those rules.

## Project status

Planning stage. The dashboard is not built yet.

## Safety notice

This project uses simulated data only.
The alert rules are for demonstration, not clinical guidance.
This is not a medical device and must not be used to diagnose,
monitor, or treat real patients.
